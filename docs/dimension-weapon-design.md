# 차원 무기 설계 (초안 2026-11-17)

두 차원의 10레벨 무기 2종을 합성해 만드는 화면 공용 무기. 1차 범위는 **숲 - 공장** 6종.

## 확정 사항 (사용자 답변)
- 재료: 양쪽 플레이어의 10레벨 무기 1개씩(숲 1 + 공장 1, 정해진 짝). 합성 시 **둘 다 소모**.
- 차원 무기는 인스턴스 1개(화면 공용)이며 **양쪽 플레이어 무기 슬롯을 1칸씩 차지**하고 양쪽 HUD 에 표시.
- 조건 충족 조합이 여럿이면 **중앙 카드는 1장, 무작위 1조합**.
- 패시브 버프·디버프는 **양쪽 합산** 적용: 배율 = max(min, 1 + ΣMul_L + ΣMul_R), 가산 = ΣAdd_L + ΣAdd_R. 합성 후 변화도 계속 반영.
- **업그레이드 없음** (완성형). 획득 후 보상 풀에서 제외.
- 뿌리 속박(Root) 무기 제거 → 숲 6종 / 공장 6종이 1:1 짝.

## 합성 조건과 보상 흐름
- 레벨업 라운드를 열 때, 왼쪽·오른쪽 무기 중 `UpgradeLevel == StepCount(10)` 인 짝이 양쪽에 모두 있으면 합성 후보.
- 두 진영 차원 조합이 숲·공장일 때만 (차원 선택 화면에서 같은 차원 중복 선택은 불가).
- 슬롯 상한은 문제 없음 (재료 2개를 빼고 1칸씩 차지 → 각 진영 순증 0).
- 중보스 보상 라운드(`isBoss`)에는 나오지 않는다. 일반 레벨업 라운드만.

## 레벨업 UI
- 중앙 카드(합성)가 있는 라운드: 양쪽 `SelectPanelGroup` 을 바깥쪽으로 밀고, 중앙에 합성 카드 1장 (재료 아이콘 2개 + 결과 이름·설명).
- 커서: 왼쪽은 D, 오른쪽은 ← 로 중앙 카드로 이동 (A / → 로 복귀). 기본 선택은 기존처럼 각 그룹 1번.
- **어느 한쪽이라도 중앙 카드를 고른 상태에서 Space** → 합성만 적용하고 라운드 종료 (다른 보상 무시).
  중앙 카드를 고르면 그 쪽 일반 카드 선택은 해제되고, 상대 쪽 선택 여부와 무관하게 재개 가능.
- 합성 카드가 없는 라운드는 기존 레이아웃 그대로.

## 화면 공간 (Stage Space)
- 최종 보스용 `BossSpace` 의 보스 월드(오버레이 카메라 2대가 보는 공간)를 **게임 시작부터** 화면 공간으로 쓴다.
  - 오버레이 배치(`LayoutOverlays`)를 `StageSpace` 공용 컴포넌트로 분리해 게임 시작 시 한 번 수행. `FinalBossDirector` 는 이를 재사용.
  - 오버레이 culling mask 에 새 레이어 `Stage` 추가 (차원 무기 렌더링). 보스 레이어는 그대로.
  - 화면 중앙 = `StageRect.center` (좌우 화면 사이 구분선).
- 진영 월드 ↔ 화면 공간 변환: 기존 `BossSpace.Translate` (진영 카메라 위치 ↔ 오버레이 위치 평행이동). 진영 카메라가 플레이어를 따라 움직이므로 매 프레임 변환.
- 화면 밖(각 진영 SideRect 밖)의 적은 대상에서 제외.

## 화면 충돌·탐색 (쿼드트리)
- `StageQuadTree`: 고정 경계(StageRect), 노드 용량 8, 최대 깊이 6. 매 프레임 1회 재구성(LateUpdate 이전, 실행 순서 지정).
- 원소: `HealthSystem.ActiveEnemies` 중 살아 있는 적 → (화면 좌표, 반지름, 진영, HealthSystem). 반지름은 콜라이더 bounds 기준 캐시.
- 쿼리: `QueryCircle(center, r, List)`, `QueryNearest(center, maxR, exclude)`, `QuerySegment(a, b, width, List)` (레이저용), `QueryRect`.
- 배열 풀·노드 풀 재사용으로 GC 0. 적 수가 적으면(< 32) 선형 탐색으로 폴백 가능하도록 내부 판단.
- 데미지: 대상 `HealthSystem` 에 기존 `DamageMassage` 파이프라인으로 직접 전달 (물리 콜라이더 사용 안 함). `DamageMassage.weapon` 은 차원 무기(통계용).
- 최종 보스 프록시도 ActiveEnemies 에 들어가므로 자동으로 타격 대상.

## 차원 무기 베이스
- `DimensionWeapon : MonoBehaviour` (기존 `Weapon` 상속 아님 — 소유자가 둘이고 물리 탐색을 쓰지 않음).
  - 화면 공간에 1개 생성, 레이어 `Stage`. 쿨타임·데미지 계산은 양쪽 `PlayerStats` 합산.
  - HUD 슬롯·통계용으로 각 진영 `PlayerStats` 에 "차원 무기 슬롯" 등록 (AddWeapon 경로와 분리한 API, 메인이 공유 파일 수정).
- `DimensionWeaponData` (SO): 이름 키, 아이콘, 재료 2종(숲 프리팹·공장 프리팹), 결과 프리팹, 수치.
- 합성 보상은 `RewardEffect` 를 상속한 `DimensionFusionEffect` 로 구현해 기존 보상 적용 흐름을 탄다.

## 데미지 기준
- 각 무기의 **10레벨 유효 DPS(버프 없음)** 두 재료의 합을 목표 DPS 로 한다.
- 기준: 모든 무기는 기본 유효 DPS 26(Sweep 32)으로 정규화, 10단계 누적 ×9 목표 (`balance-design.md` 3.2·3.3).
  → 10레벨 무기 1개 ≈ **유효 DPS 234** (Sweep ≈ 288). 회전 칼날은 DPS 대신 "60초마다 진영 전체 즉사".
- 차원 무기 목표 = 두 재료의 합. 화면 공용이라 양쪽 화면 적을 모두 상대하므로 **재료 2개의 합을 그대로** 쓴다 (추가 보너스 없음).
- 초기값은 아래 목표 DPS 에 맞춰 정하고, `WeaponTest` 씬 DPS 미터로 실측 보정한다.

| 차원 무기 | 목표 유효 DPS | 배분 |
|---|---|---|
| 정령 편대 | 468 | 정령 234 + 드론 234 |
| 가시 톱날 | 468 | 톱날 직격 234 + 덩굴 장판 234 |
| 잔영 회전검 | 288 + 즉사 | 회전 칼날 지속 288 / 잔상 즉사 주기 30초 (닿는 적만이라 회전 칼날 60초 전체 즉사보다 짧게) |
| 분광 레이저 | 468 | 1차 레이저 234 + 분기 레이저 234 |
| 역병 지뢰 | 468 | 폭발 234 + 독 장판 234 |
| 화염 부메랑 | 468 | 부메랑 주변 지속 화염 468 (1회 타격 없음) |

## 무기 6종 (숲 + 공장)

| 결과 무기 | 재료 (숲 + 공장) | 동작 요약 |
|---|---|---|
| 정령 편대 (Spirit Squadron) | 정령 + 드론 | 정령이 가장 가까운 적을 추격. 드론은 정령 주위를 돌며, 정령의 대상이 **아닌** 가장 가까운 적을 사격. 대상이 없으면 화면 중앙에서 대기 |
| 가시 톱날 (Thorn Saw) | 덩굴 + 톱날 | 톱날 수 3배, 화면 전체 폭을 가로지름. 지나간 자리에 지속 데미지 덩굴 |
| 잔영 회전검 (Phantom Whirl) | 휘두르기 + 회전 칼날 | 화면 중앙에서 칼날이 천천히 계속 회전, 닿는 적 지속 데미지. 일정 시간마다 잔상이 빠르게 1바퀴 돌며 닿는 적 즉사 (최종 보스는 즉사 면역 → 큰 데미지) |
| 분광 레이저 (Prism Laser) | 분열탄 + 레이저 | 양쪽 플레이어 위치에서 각자 가장 가까운 적에게 레이저. 맞은 적 기준 가장 가까운 적 2명에게 추가 발사, 투사체 수만큼 반복(분기) |
| 역병 지뢰 (Plague Mine) | 독 장판 + 지뢰 | 화면 무작위 위치에 지뢰 생성, 가까운 적을 천천히 추적. 폭발 시 주변 적을 끌어당긴 뒤 독 장판 생성 |
| 화염 부메랑 (Blaze Boomerang) | 부메랑 + 화염 방사 | 양쪽 플레이어 위치에서 발사. 기존 부메랑 이동 그대로, 비행 중 계속 화염 방사하며 주변 지속 데미지 (1회 타격 없음) |

### 공통 해석
- "가장 가까운 적" 은 화면 공간 거리 기준 (반대 진영 화면의 적도 포함).
- 플레이어 위치 기준 발사는 해당 플레이어 위치를 화면 공간으로 변환해 사용.
- 끌어당김(역병 지뢰)은 화면 공간 방향을 진영 월드 이동으로 변환해 적용 (평행이동이므로 방향 동일).
- 지속 데미지 영역(덩굴·독 장판·화염)은 틱마다 쿼드트리 원 쿼리.
